ONE-TIME SETUP (about 10 minutes). After this, updates run by themselves every 2 hours.

1. Create a free account at github.com
2. Click "+" > New repository. Name: sarkari-jobs. Set Public. Create.
3. Click "uploading an existing file". Unzip this package, upload ALL files
   AND the .github folder. Click Commit.
4. Settings > Pages > Source: "Deploy from a branch", Branch: main, Save.
5. Actions tab > if asked, click "I understand, enable workflows".
   Open "Update jobs" > Run workflow (fills the list the first time).
6. Your site: https://YOURUSERNAME.github.io/sarkari-jobs
